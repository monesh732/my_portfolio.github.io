Project Background

Before diving into Python, I built this system in Java to understand how desktop applications and relational databases connect end-to-end. The goal was to build something a real small business could use — not just a study exercise.

What Was Built

A full-stack Java desktop application covering every core part of running a grocery store:

  • Swing GUI — full-featured desktop interface with tabbed screens and live-updating JTable panels
  • Inventory module — add, update, search, and delete products with category, price, and stock tracking
  • Billing module — cart-style invoice builder with item totals, tax, and receipt generation
  • Customer records — customer debt/credit tracking and purchase history
  • MySQL via XAMPP — structured schema with foreign-key relationships across all modules
  • JDBC data layer — PreparedStatement queries for every CRUD path

Tech Stack

  • Java — Core application logic
  • Java Swing — Desktop GUI framework
  • MySQL — Relational database
  • XAMPP — Local PHP + MySQL stack for database management
  • JDBC — Database connectivity layer
  • NetBeans IDE — Development environment

What I Learned

This was the project that introduced me to relational database design, CRUD operations, and GUI programming. Working through JDBC queries, schema design, and the Swing event model gave me a grounded understanding of how data moves between the UI layer and the database — a foundation I still rely on when building Python APIs today.
