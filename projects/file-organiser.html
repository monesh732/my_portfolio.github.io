File Organisation Automation

A Python OS-automation script — watches the Downloads folder (or any folder) and automatically sorts every incoming file into categorised sub-folders based on its file type.

Project Background

The Downloads folder is a universal dumping ground — PDFs, installers, screenshots, archives, all mixed together. Every time I found myself dragging files into folders by hand, I thought: this is exactly the kind of repetitive task a script should handle. So I built one.

What Was Built

A Python script that runs silently in the background, monitors a folder, and keeps it clean without any manual work:

  • File watcher — polls or watches folders for new files, triggering sort logic as soon as a file lands
  • Extension mapping — maps every file extension to a category folder (images, PDFs, installers, archives, videos, audio, documents, code files)
  • Safe move — skips hidden/system files, silently ignores files still in use, and moves only confirmed targets
  • Folder creation — creates category folders on first run if they don't exist
  • Dry-run & logging — preview what would move before touching a single file; logs every action for auditability

Core Sort Logic

CATEGORY_MAP = {
    "Images": [".jpg", ".png", ".gif", ".webp", ".svg"],
    "PDFs":    [".pdf"],
    "Installers": [".exe", ".msi", ".dmg"],
    "Archives": [".zip", ".rar", ".tar.gz"],
}

RESERVED_NAMES = {"desktop.ini", "Thumbs.db"}

def sort_file(path: Path, target_dir: Path) -> str | None:
    if path.name in RESERVED_NAMES:
        return None
    category = next((c for c, exts in CATEGORY_MAP.items()
                     if path.suffix.lower() in exts), None)
    if not category:
        return None
    dest = target_dir / category / path.name
    shutil.move(str(path), str(dest))
    return category

Tech Stack

  • Python 3 — Core scripting language
  • pathlib / shutil — Cross-platform file operations
  • watchdog — Event-based folder monitoring
  • logging — Structured logs for every action taken

What I Learned

This project may be the simplest in the portfolio on paper, but it consolidated two key ideas: naming conventions as a public API, and error handling as user experience. Getting the file extension mapping right taught me to design for edge cases (Unicode filenames, locked files, files with no extension). Adding safe-move semantics and logging turned a 50-line script into something that could run unattended for months.
