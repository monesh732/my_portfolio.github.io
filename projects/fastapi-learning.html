Where This Started

I started with Flask — the Flask REST API project gave me a solid understanding of routing, database layers, authentication, and testing. FastAPI is the natural next step. It shares Flask's philosophy of staying close to the metal, but adds type-safety, async support, and auto-generated OpenAPI documentation — all derived directly from the Python type hints you already write.

What Is Being Learned

  • Pydantic models — request/response schemas defined once, automatically validated on every request
  • Async route handlers — async def endpoints with async database operations for better throughput under load
  • Dependency injection — shared logic (current user, DB session, config) injected per-request without manual boilerplate
  • Router-based architecture — modular route groups with APIRouter and tag-based grouping in the generated docs
  • Background tasks — fire-and-forget work via BackgroundTasks without reaching for Celery
  • Testing with httpx + TestClient — no real server needed during test runs

Async Route Example

from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession

router = APIRouter(prefix="/products", tags=["products"])

@router.get("/")
async def list_products(
    db: AsyncSession = Depends(get_db),   # injected dependency
    skip: int = 0,
    limit: int = 20,
) -> list[ProductSchema]:
    """Return a paginated product list."""
    result = await db.execute(
        select(Product).offset(skip).limit(limit)
    )
    return [ProductSchema.model_validate(p) for p in result.scalars()]

Tech Stack

  • FastAPI — Core framework
  • Pydantic v2 — Runtime data validation
  • SQLAlchemy 2.0 — Async ORM
  • HTTPX — Async HTTP client and test client
  • Alembic — Database migrations
  • pytest — Test suite

What Is Being Learned

The focus right now is building a reference project that mirrors the Flask API but in FastAPI — same domain (products, orders), same clean architecture, but async all the way down and dependency injection replacing manual session injection. Once this milestone is complete (all endpoints migrated, tests passing, docs generated), the path opens toward real async Python backend work at scale.
